# 步态策略 hip_yaw 长期顶限位诊断

## 问题状态

该问题已经确认：本地步态策略在训练过程中逐渐学会把两侧 `hip_yaw`
持续压向相反方向的机械限位。它最初出现在右侧，随后扩展到两侧，并在
后续训练中固化。

这不是正常的周期性关节摆动。后期策略给出的关节目标远超机械范围，实际
关节由物理限位截住，说明策略正在利用硬限位形成被动约束或支撑。

## 关节范围

| 关节 | 机械范围 |
|---|---:|
| `left_hip_yaw` | `[-0.4363, +0.5236] rad`，约 `[-25°, +30°]` |
| `right_hip_yaw` | `[-0.5236, +0.4363] rad`，约 `[-30°, +25°]` |

评估中的“贴近硬限位”定义为：实际关节位置落在完整机械范围两端各 2% 的
区域内。

## 检查点时间线

主训练链路为：

```text
0 → 250 → 499 → 500 → 750 → 998 → 1017 → 1250 → 1499
  → 1500 → 1750 → 2000 → 2250 → 2500 → 2750 → 3000 → 3250 → 3498
```

统一评估结果：

| 检查点 | 左侧平均角度 | 右侧平均角度 | 左侧贴限位 | 右侧贴限位 | 判断 |
|---:|---:|---:|---:|---:|---|
| 0 | +0.005 | +0.016 | 0.0% | 0.0% | 尚未出现 |
| 250 | -0.128 | +0.364 | 0.0% | 38.3% | 右侧开始出现 |
| 499 | -0.095 | +0.431 | 4.2% | 94.2% | 右侧基本固化 |
| 500 | -0.175 | +0.411 | 0.7% | 88.8% | 恢复训练后仍存在 |
| 750 | -0.440 | +0.442 | 99.9% | 100% | 两侧完全固化 |
| 998～3498 | 约 -0.442 | 约 +0.443 | 100% | 100% | 一直没有恢复 |

因此目前能确定：

- 异常在 `0～250` 轮之间萌芽，最先出现在右侧；
- 右侧长期顶限位最晚在 `model_499` 形成；
- 双侧长期顶限位发生在 `model_500` 与 `model_750` 之间；
- 首个能够确认双侧在所有测试命令下完全固化的检查点是 `model_750`；
- 因为没有保存 501～749 之间的检查点，无法精确到具体训练轮次。

## 与站立和步态的关系

问题并非只在迈步时出现。

`model_250` 的右侧贴限位比例已经表现出以下分布：

| 固定命令 | 右侧贴限位比例 |
|---|---:|
| 站立 | 54% |
| 前进 0.1 m/s | 0% |
| 前进 0.3 m/s | 0% |
| 后退 0.1 m/s | 50% |
| 横移 0.1 m/s | 61% |
| 左转 0.3 rad/s | 3% |
| 右转 0.3 rad/s | 100% |

这说明它可能最初与转向、横向平衡或左右不对称有关。到 `model_499`，右侧
在站立和前进时也接近 100%；到 `model_750`，两侧在站立、前进、后退、
横移和左右转向下全部接近 100%。此时顶限位已经成为默认站姿，后续步态
只是继承这个基础姿态。

## 策略目标与实际关节

后期策略目标持续越过机械范围：

| 检查点 | 左侧平均目标 | 右侧平均目标 |
|---:|---:|---:|
| 750 | -1.13 rad | +1.61 rad |
| 1499 | -1.53 rad | +3.67 rad |
| 2500 | -1.84 rad | +4.84 rad |
| 3498 | -2.02 rad | +6.17 rad |

实际关节无法到达这些目标，只能停在约 `-0.443/+0.443 rad`。这证明策略
不是偶尔碰到边界，而是在持续向机械挡块施加目标。

## 官方策略对照

在相同固定命令评估框架下，官方 `alpha_walking.onnx` 的平均关节角约为：

- `left_hip_yaw = -0.021 rad`；
- `right_hip_yaw = +0.031 rad`；
- 两侧贴近硬限位比例均为 0%。

因此，双侧 hip_yaw 长期顶限位不是官方步态的必要特征，而是本地训练策略
特有的问题。

## 评估方法与边界

时间线评估使用：

- 7 个固定命令：站立、前进 0.1/0.3 m/s、后退 0.1 m/s、横移
  0.1 m/s、左右转各 0.3 rad/s；
- 每个命令 4 个随机化回合，共 28 个回合；
- 每回合最长 6 秒，排除开始 1 秒；
- 固定随机种子 `20260923`；
- 无外部推扰；
- 所有检查点使用同一个评估环境和相同初始条件分布。

原始 JSON 和日志位于本机 `logs/hip_yaw_timeline_20260922/`，该目录被
`.gitignore` 排除，不随仓库提交。

这些结果可以可靠定位已保存检查点之间的转折，但有两个限制：

1. 检查点保存间隔较大，无法定位 500～750 之间的具体轮次；
2. 现有检查点是在此前的训练工作树上生成，而本仓库后来按要求整理为上游
   `main@1e79c29` 的独立快照。时间线采用统一评估环境做横向比较，不应被
   解读为训练过程中逐时间步的原位遥测。

## 尚未确认的原因

目前只确认了出现时间和行为模式，尚未通过消融实验确认根因。可能因素包括：

- 现有 `dof_pos_limits` 惩罚只覆盖非常靠近边界的区域，无法阻止策略把
  关节目标推到机械范围之外；
- 策略可能利用硬限位获得额外被动刚度，减少主动平衡难度；
- 左右不对称在早期首先把右侧推到限位，随后训练收敛到双侧镜像姿态；
- 500/750 轮附近同时存在动作平滑、站立样本比例、头部命令范围和 CoM
  随机化课程变化，但时间重合不等于因果关系。

在完成单因素消融前，不应把问题归因于其中任意一个参数。

## 后续处理原则

1. 保留 `model_250`、`model_499/500` 和 `model_750` 作为转折对照；
2. 后续训练必须记录两侧 hip_yaw 的实际角度、目标角度和贴限位比例；
3. 优先验证 qpos 侧的限位邻近惩罚，而不是只限制动作目标；
4. 同时检查左右对称性和站立姿态，避免仅在行走奖励上修补；
5. 通过短程 A/B 实验确认不会破坏站立和正常步态后，再进行长时间训练。
